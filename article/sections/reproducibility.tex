All the code, results, and figures are available at
\url{https://github.com/emersonheto/enem-school-performance}. The repository contains:
\begin{itemize}
  \item \emph{Data pipeline.} \texttt{scripts/build\_dataset.py} downloads the two INEP files from
        the URLs in Section~\ref{sec:data} and builds the school-level table. It records, in a
        metadata file, the URL and SHA-256 hash of each source, the counts at each step, and the
        library versions. The notebooks check these hashes before running, so a republication of
        the microdata by INEP is detected instead of silently changing the results. The SHA-256
        hashes of the files used are \texttt{b8d3e72c\ldots a116071} (ENEM 2025) and
        \texttt{ae29d81d\ldots c2d640db} (Censo Escolar 2024); the full hashes are in the
        repository.
  \item \emph{Shared preprocessing and evaluation.} The preprocessing, the grouped folds,
        spot-checking, nested cross-validation, and the statistical tests are implemented once in
        \texttt{src/enem\_school/} and imported by every notebook, so all the models use exactly
        the same data, transformations, and partitions. Unit tests (\texttt{pytest}) cover the
        data pipeline and the preprocessing rules.
  \item \emph{Notebooks.} Four notebooks reproduce the experiments in order: linear regression and
        baselines, spot-checking, nested cross-validation, and interpretation. Each writes its
        per-fold results to \texttt{reports/results/}, from which the tables of this paper are
        generated by a script, and runs either locally or on Google Colab.
  \item \emph{Environment and randomness.} Library versions are pinned in \texttt{uv.lock} and
        \texttt{requirements.txt} (Python 3.12, scikit-learn 1.9.1, SHAP 0.54.1). All random
        processes use fixed seeds: 42 for the models and the first partition, and $42 + r$ for
        repetition $r$.
\end{itemize}
The metrics are reproducible exactly; only the training times depend on the hardware.
